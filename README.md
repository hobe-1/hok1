# بوفية توب كبدة

هذه نسخة HTML مهيأة للرفع إلى GitHub Pages، وتم تحديث إعدادات Firebase لتستخدم مشروع `gggg-8085a`.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع `index.html` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واحفظ.
5. انتظر رابط الموقع الذي يظهر في صفحة Pages.

## إعداد Firebase المطلوب قبل الاستخدام
1. في Firebase Console للمشروع `gggg-8085a`، افتح **Authentication → Sign-in method** وفَعّل **Anonymous** لأن الكود الحالي يسجّل الدخول بشكل مجهول.
2. افتح **Firestore Database** وتأكد أن قاعدة البيانات موجودة.
3. اضبط قواعد Firestore بما يناسب صلاحيات المالك والكاشير قبل حفظ مبيعات حقيقية. **لا تستخدم قواعد تسمح للجميع بالقراءة والكتابة.** تسجيل الدخول المجهول وحده لا يميّز المالك عن الكاشير، ولذلك هذه النسخة ليست جاهزة للإنتاج الآمن حتى تضبط المصادقة والصلاحيات.
4. اختبر مزامنة الطلبات من جهازين بعد ضبط القواعد.

## الطباعة
الكود الحالي يرسل مهام الطباعة إلى خدمة محلية على الكمبيوتر على العنوان `http://127.0.0.1:3210`. رفع الموقع إلى GitHub لا يثبت خدمة الطباعة ولا يشغّلها. يلزم تشغيل Print Bridge على كمبيوتر الكاشير وتحديد الطابعة، وقد تتطلب الطباعة من موقع HTTPS إعدادات إضافية حسب الخدمة والمتصفح.

## ملاحظة مهمة
الرفع إلى GitHub ينشر الموقع فقط؛ لا يرفع بيانات المتجر المحلية تلقائيًا ولا يضبط Firebase نيابة عنك. لا تضع مفاتيح حساب خدمة (Service Account) أو كلمات مرور في المستودع.
